# 009. 세션 보관 기간과 쓰기 요청 제한

- 상태: Accepted
- 날짜: 2026-11-03

## Context (배경)

- ADR 008의 `sessions` 테이블은 생성 24시간 뒤 `expires_at`이 지나면 API가 404를 줄 뿐, 행을 지우는 곳이 없다.
- 행에는 사용자가 쓴 문장(`query`) 원문과 나이·시도·시군구·혼인·학력·소득 구간이 남는다. 이름·연락처·IP는 저장하지 않지만 자유 문장 내용은 통제할 수 없다. 알파 테스트(11/24~) 분석에는 24시간보다 오래 남아야 한다.
- `POST /v1/sessions`는 인증 없이 호출마다 전체 후보(약 370건)를 조회하고 INSERT한다. CORS는 curl을 막지 못한다. 행 하나는 질문 JSON(경기 시군구 선택지 31개)과 정책 ID 두 묶음으로 약 3~4KB(추정, 측정 전)다. 초당 3~10회 반복 호출이면 Render 무료 DB 1GB가 1~4일 안에 찬다. 무료 웹 서비스(0.1 CPU)는 그 전에 응답이 느려진다.
- 서버는 `--forwarded-allow-ips='*'`로 떠 있어 클라이언트가 `X-Forwarded-For`로 IP를 바꿀 수 있다.

## Decision (결정)

- **보관 30일**: 일 배치 워크플로(04:00 KST)에 적재와 별도 단계로 `python -m app.jobs.cleanup_sessions`를 둔다. 생성 후 `SESSION_RETENTION_DAYS`(기본 30)일이 지난 세션을 지운다. 적재가 실패해도 정리 단계는 돈다.
- **쓰기 요청 제한**: 메모리 기반 고정 길이 창(10분)으로 세션 생성은 IP별 20회·전체 300회, 답변은 IP별 60회·전체 900회까지 허용한다. 초과하면 429와 `Retry-After`를 준다. 조회(GET)는 제한하지 않는다.
- IP를 속일 수 있으므로 전체 상한을 함께 둔다. 막힌 요청은 기록하지 않아, IP를 바꿔 가며 보내도 기록되는 IP 수는 전체 상한 이하로 유지된다. 한 IP가 계속 보내도 전체 예산은 그 IP 상한만큼만 쓴다.
- 알파 테스트 참가자 안내에 "입력 문장과 답을 30일간 분석에 사용"을 넣는다(프론트 문구, 팀장과 협의).

## Alternatives (검토한 대안)

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|------|------|------|--------------------|
| 7일 보관 | 노출 기간 짧음 | 알파 테스트(11/24~30) 뒤 분석(12월 초) 전에 지워짐 | 분석 요구 불충족 |
| 만료 즉시 `query`만 지우고 30일 보관 | 원문 노출 최소 | 추출 규칙(`query_hints`) 개선에 원문이 필요 | 30일이면 Render 무료 DB 수명(ADR 007)과 같아 실익 작음 |
| 세션 생성 요청 때 오래된 행 함께 삭제 | 인프라 추가 없음 | 요청 경로에 쓰기 추가, 트래픽이 없으면 안 지워짐 | 이미 있는 일 배치가 맞는 자리 |
| `slowapi` 도입 | 데코레이터, 저장소 교체 쉬움 | 의존성 추가, 막힌 요청 미기록·전체 상한 조합은 직접 구성 필요 | 단일 인스턴스에는 작은 모듈 하나로 충분 |
| IP별 제한만 | 단순 | `X-Forwarded-For` 위조로 우회, IP별 기록이 무한히 늘 수 있음 | 전체 상한이 비용·메모리 상한을 보장 |
| `forwarded-allow-ips`를 Render 프록시 대역으로 좁힘 | IP 위조 차단 | Render 프록시 IP 대역이 공개·고정돼 있지 않음 | 확인 전까지 전체 상한으로 대체 |

## Consequences (결과)

- 세션 저장량 상한: 생성은 10분에 300건, 하루 최대 약 43,000건(약 150MB, 추정)이고 30일 뒤 지워진다. 실제로는 Render DB 만료(30일)와 같은 주기다.
- 감수하는 것:
  - 전체 상한에 걸리면 정상 사용자도 429를 받는다. 알파 테스트 규모(15명)에서는 닿지 않는 값이다.
  - 재배포·슬립 후 기동하면 카운터가 초기화된다. 인스턴스를 늘리면 인스턴스마다 따로 센다(공유 저장소 필요).
  - `POST /v1/candidates`(읽기 전용, 후보 50건)는 제한하지 않았다.
- 후속: 알파 테스트 전 실제 행 크기 측정, 참가자 안내 문구 확정.

## 이력서·면접용 한 줄

"인증 없는 무료 서버에서 세션 저장 API의 남용 위험을 IP 위조까지 고려한 IP별·전체 이중 상한과 30일 보관 배치로 막아, 저장량 상한을 하루 약 4만 건으로 고정함"
