# 012. 역질문 LLM 문구화: text만 다듬고 변수·선택지는 서버 고정

- 상태: Accepted
- 날짜: 2026-11-16

## Context (배경)

- ADR 008에서 변수 선정·선택지 `value`/`label`은 서버가 정하고, 질문 문구는 우선 템플릿으로 두었다. 선정 사유 LLM(ADR 011)은 이미 들어갔고, 파이프라인 빈칸은 역질문 `text`가 여전히 템플릿뿐인 점이었다.
- LLM이 변수·선택지까지 다시 쓰면 필터 코드와 어긋날 수 있다. 옵션 label(코드표·시군구 공식명)을 바꾸면 칩 UI와 답 검증이 흔들린다.
- 세션 생성은 이미 전체 후보 조회가 있어 무겁다. LLM을 요청 트랜잭션 안에서 기다리면 Render 무료 플랜 커넥션 풀을 점유한다(ADR 011과 같은 제약).
- CI·로컬은 OpenAI 키 없이 돈다. 키 없음·타임아웃·스키마 불일치에도 세션 생성은 201이어야 한다.

## Decision (결정)

- **변경 허용은 `text`만.** `id`·`variable`·`type`·`options`(value·label)·`affected`는 서버가 고른 값을 그대로 저장한다. 옵션 label 재작성은 하지 않는다.
- **호출 시점**: `POST /v1/sessions` 생성 경로만. 답변·조회는 세션에 저장된 `questions`를 쓴다.
- **연결 밖 호출**: 후보 조회·질문 선정 후 DB 연결을 닫고 `phrase_questions` → INSERT. 선정 사유와 같이 LLM 대기 중에는 커넥션을 잡지 않는다.
- **입출력**: 프롬프트에는 `query`와 `[{id, variable, text}]`만 넣고 후보 목록·선택지는 넣지 않는다. LLM 출력은 `[{id, text}]`이며, 서버가 id 집합을 대조한다. 빠진 id·빈 text·URL/날짜 언급은 해당 질문의 템플릿 `text`를 유지한다.
- **폴백**: 키 없음(`llm is None`)·`LlmError`·출력 불일치면 템플릿 질문 그대로 INSERT. `reason_source`와 같은 철학이지만, 질문 스키마에 `text_source` 필드는 두지 않는다(필요하면 이후).
- **캐시 없음**: 세션마다 변수 조합이 다르고 생성 1회이므로 세션 JSON에 최종 문구만 저장한다.
- **기존 클라이언트 재사용**: `app/llm/client.py`의 `LlmClient.parse` + Pydantic. 요청 제한은 기존 `CREATE_LIMIT` 유지(실측 후 조정).

## Alternatives (검토한 대안)

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|------|------|------|--------------------|
| 템플릿 문구만 유지 | 비용·환각 0 | 칩 질문이 딱딱함 | 서비스 체감이 약함. 폴백으로는 유지 |
| LLM이 변수·선택지까지 생성 | 구현이 단순해 보임 | 필터·답 검증과 어긋남 | ADR 008 위반 |
| 옵션 label만 구어체로 재작성 | 칩이 더 자연스러움 | 공식명·코드표와 불일치, 환각 면 확대 | 이번 범위에서 제외 |
| 선정 사유처럼 세션 캐시 | 재생성 비용 절감 | 질문은 생성 1회·조합이 다양 | 세션 행에 저장하면 충분 |
| 생성 트랜잭션 안에서 LLM 호출 | 코드 단순 | 커넥션 점유 | ADR 011과 동일하게 분리 |

## Consequences (결과)

- 얻는 것:
  - 질문 문장은 자연스러워지고, 답 검증·재필터는 여전히 `option.value`만 본다.
  - 키 없음·LLM 실패에도 템플릿으로 201 생성한다. 가짜 LLM 테스트로 폴백·id 불일치·답변 무관을 고정한다.
  - 후보 JSON을 프롬프트에 넣지 않아 질문 쪽 토큰은 이미 작다.
- 감수하는 것:
  - 세션 생성 지연이 LLM 한 번만큼 늘어난다(실측 전).
  - LLM이 자격·지역명을 `text`에 새로 넣으면 정규식·날짜 필터로만 일부 막는다. 표본 점검이 필요하다.
- 후속 과제: 프롬프트 경량화(선정 사유 쪽, 8주차), FE 연동, 서류 준비 지원(A+B).

## 이력서·면접용 한 줄

"역질문에서 LLM은 서버가 고른 질문의 text만 다듬게 하고 id·변수·선택지는 대조·고정해, 키 없음·호출 실패에도 템플릿 질문으로 세션을 만들면서 칩 답 검증은 option.value로 유지함"
