# 013. 가짜 전국 필터와 시도 고정 역질문

- 상태: Accepted
- 날짜: 2026-11-20

## Context (배경)

- ADR 006은 시군구 코드 200개 이상을 전국으로 보고, 시도 미입력이면 전국만 남긴다. 그런데 zipCd가 전국처럼 채워진 기초지자체 사업(예: 의성군)이 그 필터를 통과해, 지역 없는 주거 질의 상위가 의성군으로 고정되는 경우가 있다.
- 같은 행이 `sido_codes`에 서울 등을 포함하면 시도 입력이 있어도 타 지역 사용자에게 붙는다. UI가 `region_scope=national`이면 "전국" 배지도 붙는다.
- 시도가 없으면 지역 정책을 아예 못 고르고, 기대 제거율만으로는 시도 질문이 앞에 안 올 수 있다. 세션 기억·`exclude`/`offset`은 별 이슈로 두고 결과 품질만 다룬다.

## Decision (결정)

- **가짜 전국**: `cardinality(sigungu_codes) ≥ 200`이어도 `org_name`이 기초지자체 패턴이면 전국으로 취급하지 않는다.
  - 기초지자체 예: `시청`/`군청`/`구청`, `군 `/`구 `, 또는 `(특별자치)도` + 공백 뒤 `시`·`군` (예: `경상북도 의성군 …`). `경기도청`·중앙부처는 제외.
  - **유효 전국** = 전국 zip ∧ ¬기초지자체.
  - 시도 없음 → 유효 전국만. 시도 있음 → 기존 `sido_codes` 포함 유지 + 가짜 전국은 기관명에 해당 시도 한글명(`codes.SIDO`)이 있을 때만 통과.
  - `region_rank` / 카드 `region_scope`: 가짜 전국은 `sigungu` (전국 배지 금지). 판정은 쿼리 타임(`region_scope` 헬퍼), 재적재 없음.
- **시도 고정 역질문**: `conditions.sido_code is None`이면 세션 생성 시 시도 질문(`QuestionVariable.SIDO`)을 맨 앞 고정 삽입. 선택지는 `codes.SIDO`, 답 `value`는 2자리 코드. 시군구 질문은 기존대로 시도가 이미 있을 때만. 시도 답을 나중에 받아도 질문은 재생성하지 않는다(MVP).

ADR 006·008을 보완하며 supersede하지 않는다.

## Alternatives (검토한 대안)

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|------|------|------|--------------------|
| zipCd 재적재로 원문 교정 | 데이터 근본 수정 | 파이프라인·검증 범위 큼 | 이번은 쿼리 타임으로 품질만 고침 |
| 시군구 200개면 무조건 전국 | 단순 | 의성군형 가짜 전국이 상위 고정 | 체감 품질이 깨짐 |
| 기관명만으로 전국 판정 | zip 오탐 회피 | 중앙부처·광역 표기가 들쭉날쭉 | zip∩기관명 조합이 오탐이 적음 |
| 시도 질문도 기대 제거율만 | 기존 엔진과 동일 | 시도 미입력 시 지역 정책 진입 불가 | 맨 앞 고정이 더 확실 |
| 시도 답 후 질문 재생성 | 시군구 칩까지 이어서 물음 | 세션·FE 복잡도 | MVP는 시도까지만 허용 |

## Consequences (결과)

- 얻는 것: 시도 없는 질의에서 기초지자체 가짜 전국이 후보·상위에서 빠짐. 서울 사용자에게 의성군 사업이 안 붙고, 경북이면 `region_scope=sigungu`로 남음.
- 감수하는 것 / 후속: 생성 시 시도가 없어 시군구 질문이 안 붙었으면 그 세션은 시도까지만. `exclude`/`offset`·Redis·zip 재적재는 범위 밖. 개발 DB 오분류 건수는 측정 전.

## 이력서·면접용 한 줄

"시군구 200개 zip만으로 전국을 보던 필터가 기초지자체 사업을 전국으로 올리던 문제를, 기관명 패턴으로 가짜 전국을 걸러 region_scope를 sigungu로 내려 타 지역·무지역 질의 상위 고정을 막음"
