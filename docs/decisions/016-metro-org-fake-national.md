# 016. 광역 지자체 기관의 가짜 전국 확장

- 상태: Accepted
- 날짜: 2026-11-28

## Context (배경)

- 「서울 사는 자취생 지원금」 결과에 대구광역시 정책(귀환 청년 주거지원)이 "전국" 배지로 노출됐다. 온통청년 원문 `zipCd`가 시군구 247개(서울 포함)로 채워져 있었고, ADR 013의 가짜 전국 판정은 기초지자체(시·군·구) 패턴만 봐서 "대구광역시 …" 기관은 유효 전국으로 통과했다.
- 로컬 DB 실측(`journal/2026-11-28-metro-fake-national.md`): 전국 zip 710건 중 기초 가짜 전국 21건 제외 후에도 유효 전국 689건에 **기관명에 광역 시도명이 포함된 정책 87건(12.6%)** 이 남아 있었다(신청 가능·상시 39건). 대부분 해당 지역 주민 대상 사업이다. "타지역 청년 유치" 성격(이름에 귀환·유치·타지역)은 4건뿐이다.

## Decision (결정)

- 전국 zip ∧ (기초지자체 패턴 ∨ **기관명에 `codes.SIDO` 한글명 포함**) → 가짜 전국. 유효 전국 = 전국 zip ∧ ¬지자체 기관.
  - ADR 013이 제외했던 "경기도청"처럼 광역만 있는 이름도 이제 지자체 기관으로 본다.
  - 중앙부처·공공기관은 시도명이 없으면 영향 없음.
- 시도 입력이 없으면 가짜 전국은 후보에서 빠진다. 시도가 있으면 기존대로 `sido_codes` 포함 ∧ 기관명에 그 시도명이 있을 때만 통과.
- `region_scope`: 기초지자체 가짜 전국은 `sigungu`(ADR 013 유지). **광역 기관이 사용자 시도 사업이면 `sido`**(대구 사용자에게 대구광역시 정책). 판정은 쿼리 타임, 재적재 없음.

ADR 013을 보완하며 supersede하지 않는다.

## Alternatives (검토한 대안)

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|------|------|------|--------------------|
| zipCd 교정·재적재 | 근본 수정 | 원문이 온통청년 데이터, 우리가 교정 불가 | 쿼리 타임으로 충분 |
| 이름에 귀환·유치 키워드만 예외 | "타지역 청년 유치" 보존 | 키워드 의존, 4건뿐 | 단순함 우선, 시도 입력 시 해당 지역엔 노출 |
| 광역 기관을 항상 유효 전국 유지 | 변경 없음 | 87건 타 지역 노출 | 체감 품질 문제 |

## Consequences (결과)

- 얻는 것: 가짜 전국 21 → 108건, 유효 전국 689 → 602건. 「서울 자취생 지원금」·서울 시도 입력에서 대구 정책 제외, 대구 시도 입력에서는 `sido`로 노출.
- 감수하는 것: 서울 거주자가 대구 취업을 검토하는 "타지역 청년 유치" 정책(약 4건)은 서울 질의에서 빠진다. 신청 링크가 목록·인덱스 페이지인 URL 품질 문제는 별도 과제(범위 밖).

## 이력서·면접용 한 줄

"광역 지자체가 낸 사업이 전국 zip으로 등록돼 타 지역 사용자에게 노출되던 문제를 실측(유효 전국의 12.6%)으로 확인하고, 기관명 기반 판정을 광역까지 확장해 87건을 지역 한정으로 내림"
