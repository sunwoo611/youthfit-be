# 2026-11-20 가짜 전국 필터·시도 고정 역질문

## 상황 / 증상

지역 없는 주거 질의에서 zipCd가 전국처럼 잡힌 기초지자체(예: 의성군) 사업이 상위 고정. 시도 미입력이면 지역 정책에 진입할 역질문도 없었다.

## 원인 분석

- ADR 006의 `sigungu ≥ 200`만으로 전국을 보면 기초지자체 가짜 전국이 통과한다.
- 기대 제거율만으로는 시도 질문이 앞에 오지 않고, 시도 없으면 후보가 유효 전국에 묶인다.

## 해결

- 쿼리 타임 가짜 전국 판정(`region_scope.py`): 유효 전국 = 전국 zip ∧ ¬기초지자체. 가짜 전국은 해당 시도 기관명일 때만·`region_scope=sigungu` (ADR 013).
- 시도 미입력이면 `QuestionVariable.SIDO`를 세션 질문 맨 앞 고정 삽입. 시군구는 생성 시 시도가 있을 때만(재생성 없음, MVP).
- FE: 지역 배지는 `eligibility.region_scope`만. `sido` 칩 `affected`는 항상 0.

`region_rank`가 시도 전체로 올라가던 회귀는 별도 기록: `journal/2026-11-20-fake-national-region-rank.md`.

## 결과 (수치)

로컬 DB(`policies` 적재본, Docker 기동 후 집계, 2026-11-20):

| 구분 | 건수 |
|------|------|
| 전체 정책 | 3,602 |
| 전국 zip (`sigungu ≥ 200`) | 694 |
| 가짜 전국 (전국 zip ∧ 기초지자체 기관명) | **19** (정규식 수정 전 20) |
| 유효 전국 (전국 zip − 가짜 전국) | 675 |

- 시도 미입력 시 이전에는 전국 zip 694건이 후보에 들어올 수 있었고, 필터 후 **19건이 탈락**해 유효 전국 675건만 남는다.
- 가짜 전국 19건: 의성군 관광복지국 8건, 익산·화순·장흥·함안·의령·용인·은평·구청장 등.
- 오탐 수정: `경상북도 지방시대정책국 청년정책과` — `(도)\s+\S*[시군]`이 `시대`의 `시`에 걸리던 것을 `(?:시|군)(?:\s|$)`(토큰 끝)으로 좁혀 유효 전국으로 복구.
- 단위·픽스처: `fake_national`·`is_basic_local_org` 회귀 테스트 통과. 시도 고정 질문은 엔진 단위 테스트 통과.

## 배운 점 / 재발 방지

- 집계 전 Docker/`youthfit-db`가 떠 있는지 확인한다. URL이 localhost여도 데몬이 꺼져 있으면 연결 타임아웃만 난다.
- 전국 zip 픽스처는 법정 시군구 혼합으로 만들어야 `region_rank` 회귀를 잡는다.
- MVP로 질문 재생성을 빼면 전국 풀이 얇을 때 칩이 `sido`만 남을 수 있다(ADR 감수).
- `도 …시/군` 매칭은 글자 포함이 아니라 토큰 끝으로 둔다 (`시대` 오탐).
