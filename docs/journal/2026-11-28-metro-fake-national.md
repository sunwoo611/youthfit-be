# 2026-11-28 광역 기관 전국 zip 오노출

## 상황 / 증상

「서울 사는 자취생 지원금」에 대구광역시 "귀환 청년 주거지원(공공기관 사택제공)"이 전국 배지로 노출. 신청 링크는 대구시 청년정책 사이트 인덱스(`daegu.go.kr/YouthPolicy/index.do?menu_id=…`)로 본문이 비어 있었다.

## 원인 분석

1. 수집 오류 가설 기각: 온통청년 API 원문 대조 결과 `aplyUrlAddr`·`zipCd`(247개) 모두 원문 그대로. 추가 자격은 "대구에 관심 있는 전국 청년(타지역)"이라 zip 전국 자체는 의도에 가깝다.
2. 필터 빈틈: ADR 013의 가짜 전국 판정은 기초지자체(시·군·구)만 대상. 광역 기관은 유효 전국으로 통과.
3. 링크 문제는 기관이 등록한 URL 품질 문제로 우리 쪽에서 교정 불가.

## 해결

기관명에 `codes.SIDO` 한글명이 있으면 지자체 기관으로 보고 전국 zip이어도 가짜 전국 처리(ADR 016). 광역 기관이 사용자 시도 사업이면 `region_scope=sido`.
