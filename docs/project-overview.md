# 청핏(YouthFit) 프로젝트 개요

> 2026-2 고려대학교 산학캡스톤디자인. 2인 팀(백엔드·데이터·AI: 김선우 / 프론트엔드: 이승준).

## 한 줄 요약

자연어 한 문장을 입력하면 LLM이 **핵심 조건 3~5개를 역질문(선택형 칩 UI)** 하고, 청년 **정책 지원금 + 우대금리 적금**을 **자격 근거와 공식 URL**과 함께 통합 추천하는 서비스.

## 해결하려는 문제

- 정책·금융 정보가 파편화되어 있고 수십 개 필터를 직접 골라야 하는 탐색 병목
- 기준 중위소득, 고용보험 이력 등 사용자가 스스로 판단하기 어려운 조건
- 일반 챗봇의 환각(허위 자격 조건, 잘못된 마감일/URL)과 긴 입력의 피로도

## 핵심 설계 원칙

1. **Frictionless UX**: 한 문장 + 3~5회 터치로 1~2분 내 추천
2. **Efficiency**: 후보 축소는 SQL/메타데이터, LLM은 역질문 생성과 근거 서술에만 사용
3. **Trust**: DB에 있는 검증된 메타데이터·공식 URL만 노출 (Constrained Generation)

## 데이터 소스

- 온통청년 Open API (청년정책)
- 금융감독원 금융상품한눈에 API (정기예·적금)
- 일 1회 배치로 PostgreSQL에 미러링, 요청 시 외부 API 실시간 호출 안 함

## MVP 범위

- 서울·경기 핵심 청년정책 50~100건 + 금감원 공시 적금
- 이후 전국 지자체로 확대

## 백엔드 담당 범위

공공 API 수집 파이프라인, 자격 요건 정규화·DB 설계, 1차 룰 필터, 역질문 생성·RAG 근거 매칭, FastAPI REST API, 캐싱·배포.
